# seat-view

東京の主要な映画館で、各座席からスクリーンがどう見えるかを 3D で確認できる非公式の参考サイト(UI は日本語)。予約・決済機能はありません。

収録している劇場:

| タブ | 劇場 | 方式 | スクリーン(公表値) | 座席数(公表値) |
| --- | --- | --- | --- | --- |
| 池袋 | グランドシネマサンシャイン 池袋 シアター12 | IMAXレーザー/GT | 25.8 × 18.9m | 542+車椅子2 |
| 新宿 | TOHOシネマズ 新宿 スクリーン9 | TCX・ドルビーアトモス | 19.0 × 8.0m | 499+車椅子2 |
| 日比谷 | TOHOシネマズ 日比谷 スクリーン1 | TCX・ドルビーアトモス | 19.8 × 8.3m | 436+車椅子3 |

- 座席表で席にカーソルを合わせる/タップすると、その席からの眺めに切り替わる
- 距離・スクリーンが占める視野角・見上げる角度・中央からのずれを計算し、100点満点の視野スコアを表示
- 座席表はスコアで色分けでき、特別席(プレミア ボックス シート等)は幅広で表示
- タップした席は比較リスト(最大6席)に入り、スコアを並べて比べられる
- `#gcs-imax` などの URL ハッシュで劇場を直接開ける

依存ライブラリなし、ビルド不要の静的サイト。3D は素の WebGL で描画しています。

## データの正確さについて

スクリーンサイズと座席数は劇場の公表値です。列名・席番号の範囲・特別席の列は、公式の施設紹介や劇場レポートなどの公開情報から復元しています。最前列までの距離、段差、横通路の位置、前方ブロックの席数は推定値です。画面にも「推定」と出典を表示しています。

## 劇場を追加・修正する

`app.js` 冒頭の `HALLS` を編集します。長さの単位はメートルです。

```js
rows: [
  ['A', '9-10|11-30|31-32', { rise: 0 }],            // 左|中央|右 のブロックごとの席番号
  ['G', '1-10|11-30|31-40', { gap: 1.3, rise: 0.45 }], // gap = 前の横通路, rise = 段差
  ['R', '1-10|11-20|21-30', { kind: 'grand', only: 'center', pitch: 1.5 }],
]
```

- `first` はスクリーンから最前列までの距離、`pitch` は列の間隔、`riser` は既定の段差、`ideal` はスコアが最大になる水平視野角
- `rise` を省略した列は、直前に指定した段差を引き継ぐ
- `kind` は `KINDS`(premium / box / luxury / grand)のいずれか。`only: 'center'` で中央ブロックだけ特別席になる
