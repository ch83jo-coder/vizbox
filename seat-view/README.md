# seat-view

映画館の座席を予約する前に、その席からスクリーンがどう見えるかを 3D で確認できるアプリ(UI は日本語)。

- 座席表で席にカーソルを合わせる/タップすると、その席からの眺めに切り替わる
- 距離・スクリーンが占める視野角・見上げる角度・中央からのずれを計算し、100点満点の視野スコアを表示
- 座席表はスコアで色分けでき、「おすすめの席」をワンタップで選べる
- 前の観客の頭、場内照明、テストパターンの表示を切り替えられる
- 上映館は3種類(スタンダード/ラージスクリーン/プライベート)。座席の埋まり具合はシード固定の疑似乱数
- 料金は円表示。予約ボタンはデモで、実際の予約や決済は行わない

依存ライブラリなし、ビルド不要の静的サイト。3D は素の WebGL で描画しています。

## ローカル確認

```bash
npx serve .
```

## 上映館を変える

`app.js` 冒頭の `HALLS` を編集します。長さの単位はメートルです(`first` はスクリーンから最前列までの距離、`riser` は1列ごとの段差、`ideal` はスコアが最大になる水平視野角)。

## デプロイ

Vercel で Root Directory を `seat-view` に設定。Framework Preset は Other、Build Command は空欄。
